    Amazonでの割引戦略: セラースプライトを活用したアプローチ

    Amazonは世界最大のECサイトであり、多くの販売者が利用しています。そのため、商品の数も膨大であり、競争も激しいです。そこで、割引戦略は非常に重要な要素となります。

    Amazonでは、セラースプライトという機能があります。これは、セラーが自由に設定できる割引キャンペーンのことです。今回は、これを活用した割引戦略を紹介します。

    セラースプライトの設定方法

    まず、セラースプライトの設定方法について説明します。Amazonのセラーセントラルにログインし、プロモーションタブから「セラースプライト」を選択します。そこで、新しいプロモーションを作成します。商品のASINや割引率、期間などを設定し、キャンペーンを作成します。

    さらに、セラースプライトには、「クリックで割引」という機能があります。これは、商品ページ上に割引のバナーを表示し、クリックすると割引コードが表示されるというものです。設定方法も同様にプロモーションタブから行えます。

    割引戦略の具体例

    ここでは、割引戦略の具体例をいくつか紹介します。

    1. 新商品のプロモーション
    商品を新しく出品した場合、まだ評価も少なく売れるか不安です。そこで、セラースプライトを使って新商品を割引で販売することで、商品の認知度を上げることができます。

    2. 売れ行きの悪い商品の販売促進
    売れ行きの悪い商品に対してセラースプライトを活用することで、販売促進を行うことができます。割引率を設定して、商品ページにバナーを表示することで、クリック率や販売数を上げることができます。

    3. 期間限定のビッグセール
    セラースプライトを使って、期間限定のビッグセールを開催することも可能です。セラースプライトを使えば、割引率の設定や期間の設定を簡単に行うことができます。

    実際にコードを書いてみる

    実際に、セラースプライトを使った割引戦略を実装するために、以下のコードを参考にしてみましょう。ここでは、商品ページに「クリックで割引」のバナーを表示するコードを書いてみます。

    1. ボタンの作成
    割引コードを表示するボタンを作成します。コードは、商品ページのボタンの箇所に追加することで表示されるようになります。

    
<form action="https://www.amazon.co.jp/gp/deals/promoDeliveryPopup/?claimCode=">
  <button type="submit" class="discount-btn"></button>
</form>

    2. セラースプライトの情報を取得
    セラースプライトの情報を取得するために、AmazonのAPIを使用します。以下のように、セラースプライトの情報を取得するためのクラスを作成します。

    
class SellerSprintAPI {
  constructor(merchantId, token, marketplace) {
    this.urlPart = `https://api.amazon.co.jp/sp/products/${merchantId}?marketplace=${marketplace}`;
    this.headers = {
      "Authorization": `Bearer ${token}`
    };
  }

  async getSprint() {
    const res = await fetch(this.urlPart, {
      method: 'GET',
      mode: 'cors',
      headers: this.headers,
    })

    // セラースプライトの情報を取得
    const sprint = res.json();
    return sprint;
  }
}

    3. バナーの表示
    取得したセラースプライトの情報をもとに、バナーを表示するコードを書きます。

    
const api = new SellerSprintAPI(merchantId, token, marketplace);
const sprint = await api.getSprint();

// バナーを表示
if (sprint) {
    const discountBtn = document.querySelector(".discount-btn");
    discountBtn.setAttribute("href", discountBtn.getAttribute("href") + sprint.claimCode);
}

    以上のコードを商品ページに追加することで、「クリックで割引」のバナーを表示することができます。セラースプライトの設定方法や、割引戦略の具体例を参考に、自社の商品に合った割引戦略を実践してみてください。

    まとめ

    Amazonでの割引戦略は、商品の認知度を上げたり、売り上げを伸ばしたりするために非常に重要です。セラースプライトを活用することで、簡単に割引キャンペーンを作成することができます。また、APIを使用することで、より柔軟な割引戦略を実施することも可能です。これらの方法を活用し、効果的な割引戦略を立てて、販売促進につなげていきましょう。
